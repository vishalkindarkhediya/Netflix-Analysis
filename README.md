# Netflix Content Analytics Dashboard

## 📌 Project Overview

This project analyzes Netflix's content catalog using Power BI
to identify trends and patterns across Movies and TV Shows.

## 🎯 Business Problem

Netflix has a large content library containing titles from
different countries, genres, ratings, and release years.
The objective of this project is to transform raw Netflix
data into meaningful insights about the content catalog.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- CSV

## 📊 Key Analysis

- Total Netflix Titles
- Movies vs TV Shows
- Content Growth Over Time
- Top Genres
- Top Countries
- Rating Distribution
- Movie Duration Analysis

## 🔄 Data Preparation

- Removed duplicate records
- Handled missing values
- Cleaned text fields
- Converted date fields
- Transformed duration values
- Removed invalid records
- Created analytical columns
